# Team memory

The shared memory of the project. How to use it: `../TEAM.md`, section 3.

| File | Purpose |
|---|---|
| `LOG.md` | project journal: one entry per work session, newest first |
| `DECISIONS.md` | numbered decisions (D1, D2, ...) that bind everyone |
| `FINDINGS.md` | index of results, with status done or confirmed |
| `notes/<ID>.md` | the working notebook of one scenario or component |
| `notes/_TEMPLATE.md` | template for a new notebook |
