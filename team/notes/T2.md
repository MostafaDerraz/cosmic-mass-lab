## T2.1: the definitions (done)

`python tools/t2_definitions.py` writes `scenarios/T2/definitions.json`:

- the grid of `docs/05`, T2: L1a-L1e x sign (+, -) x direction (radial, perpendicular, velocity, torque) x inertia (Re, Sh, abs) = 120 cells;
- **102 definitions**, each with a stable ID `<reading><sign><direction>.<inertia>` (for example `L1a+radial.Re`) and a `law` block that a `settings.json` accepts unchanged, with lambda = 1, all terms, the moving-body term off and the range 1/r^2 (D47, the default exploratory law);
- **18 cells not applicable**: L1e with the directions other than radial (D45).

The tool checks every entry against the engine: each of the 102 builds its law, and each of the 18 is refused, so the file and the engine cannot drift apart. `engine/tests/test_t2_definitions.py` runs `--check` in CI. Changing an ID changes every reference to it in the survival table, so the IDs and their order are tested too.
