- **Build backend:** setuptools (>= 77, for the SPDX `license = "MIT"` field). The package is found in `engine/` (`[tool.setuptools.packages.find] where = ["engine"]`), so `engine/tests/` is not shipped in the package.

- **`.gitignore`:** added `*.egg-info/`, `build/`, `dist/`, `.pytest_cache/`, `.coverage`, `htmlcov/`, `.venv/`, because the editable install and pytest create them.
